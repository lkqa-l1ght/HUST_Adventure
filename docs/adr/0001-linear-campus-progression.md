# Linear Campus Progression

A run in Hust Adventure follows a strict linear sequence of five stages: Map 1 (Outside), Map 2 (Floor 1), Map 3 (Library), Map 4 (Computer Lab), and Final Map (Boss Room). Advancing to the next map requires clearing enemy waves and collecting that map's designated Key Item to unlock the portal, structuring the roguelite experience as a narrative academic journey toward the thesis defense.

## Status

Accepted

## Considered Options

- **Hub-and-spoke / Non-linear selection**: Player chooses which campus building to tackle from a central courtyard. Rejected to ensure a controlled difficulty curve and narrative pacing.
- **Wave-clear-only transition**: Portals open automatically when enemies are cleared. Rejected because requiring a thematic Key Item creates a clear exploration objective for each area.
